# AutoCore Design Tokens (Web)

**Date:** 2026-10-10 · **Status:** proposal, nothing applied yet.
**Rules:** [AUTOCORE_DESIGN_LANGUAGE.md](./AUTOCORE_DESIGN_LANGUAGE.md) · **Evidence:** [AUTOCORE_DESIGN_AUDIT.md](./AUTOCORE_DESIGN_AUDIT.md)

This document maps the design language onto the token pipeline that already exists in the repository. It adds as few tokens as possible: most of the system is already there.

---

## 1. Architecture (existing, keep)

```text
packages/design-tokens/src/colors.ts      ← single source of truth for colour (web + mobile)
        │  renderTokensCss()  (packages/design-tokens/src/css.ts)
        ▼
src/styles/design-tokens.css               ← GENERATED (npm run tokens:build), :root + .dark
        │  @import in src/app/globals.css
        ▼
src/app/globals.css  @theme inline { --color-*: var(--*) }   ← exposes colours to Tailwind v4
        ▼
Tailwind utilities  bg-card, text-muted-foreground, border-danger-border …
        ▼
components (cva variants in src/components/ui/*)

autocore-mobile/theme/colors.ts re-exports the same package.
scripts/design-tokens/check-contrast.mjs asserts contrastContract (CI: npm run tokens:check).
```

Facts the proposal relies on:
- Tailwind is **v4.3.0** with CSS-first configuration; there is no `tailwind.config.*`. Theme values are declared in `@theme` blocks.
- `cssVariableName()` turns any new key in `colors.ts` into a CSS variable automatically (`gridSelection` → `--grid-selection`). New colour keys only need (a) a value in `colors.ts` and (b) one `--color-*` line in `@theme inline`.
- Non-colour values are **not** generated by the package today (only `--radius`). They belong in `globals.css`.

**Placement rule**

| Kind | Lives in | Why |
| --- | --- | --- |
| Colour | `packages/design-tokens/src/colors.ts` | Shared with mobile, contrast-checked |
| Type scale, shadows, easing | `@theme` in `src/app/globals.css` | Tailwind v4 namespaces (`--text-*`, `--shadow-*`, `--ease-*`) generate utilities |
| z-index, durations, control sizes | `:root` in `src/app/globals.css` | No Tailwind theme namespace; consume with `z-(--z-popover)`, `duration-(--duration-fast)` |
| Spacing | Tailwind default `--spacing: 0.25rem` | Already used everywhere; do not redefine |
| Radius | Existing `--radius` scale in `@theme inline` | Keep |

## 7. Mobile impact

`autocore-mobile/theme/colors.ts` re-exports the package, so every Δ in §2 also changes mobile. The changes improve contrast on mobile for the same reasons, but they need a visual check on the dock, primary buttons and charts before release. New keys are additive and unused by mobile until adopted.
